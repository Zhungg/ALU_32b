# Signoff and stage reports

Reports generated by Innovus 20.10 for `alu_top`, grouped by type, then by flow stage.
All files are plain text (the tool's `.gz` reports were decompressed and given a `.rpt`
suffix). Host paths are replaced by `<PROJ_ROOT>` / `<HOME>`.

Raw Voltus/EM databases, `era_*` directories, EM model files and the full per-net antenna
report (~10 MB) are not included — see [../README.md](../README.md#not-in-the-repository).

## Layout

```text
signoff/
├── timing/
│   ├── 1_place_opt/          after place_opt_design   (pre-CTS)
│   ├── 2_post_cts/           after CCOpt CTS, and after post-CTS opt_design
│   ├── 3_post_route/         post-route timeDesign (setup + hold)   <- numbers quoted in README
│   └── 4_post_route_rerun/   same post-route check re-run on the final database
├── power/                    post-route power (FUNC_SETUP_VIEW)
└── physical_verification/    DRC, connectivity, placement, antenna, PG checks
```

## Timing summary per stage (reg2reg WNS, all views)

| Stage | Setup WNS (ns) | Hold WNS (ns) | Violating paths | Folder |

| Post-CTS | +1.509 | +0.028 | 0 | `timing/2_post_cts/` |
| Post-CTS opt | +1.513 | +0.028 | 0 | `timing/2_post_cts/` (`alu32_post_opt_*`) |
| **Post-route (final)** | **+1.537** | **+0.029** | **0** | `timing/3_post_route/`, `timing/4_post_route_rerun/` |

Setup is checked at the slow corner (0.9 V / 125 °C), hold at the fast corner
(1.1 V / 0 °C), for both the functional (10 ns) and scan (50 ns) constraint modes.

## File types

| Suffix | Content |
| :--- | :--- |
| `*.summary.rpt` | `time_design` summary: WNS/TNS, violating paths, DRV counts |
| `*_all/_default/_reg2reg.tarpt.rpt` | Detailed timing paths per path group (`_hold` = hold analysis) |
| `*.cap/.fanout/.length/.tran.rpt` | Design-rule (max cap / fanout / length / transition) reports |
| `*.slk.rpt`, `*.slk` | Endpoint slack tables |
| `*.SI_Glitches.rpt` | Signal-integrity glitch analysis |
